# 专属工作台 · Personal Workbench

一个**纯静态、零后端**的个人工作台网站：待办、投资跟踪（A股/ETF 实时行情）、记账本、小孩教育打卡、常用入口，并打通微信（快捷录入 + 云端多设备同步）。

> 数据默认保存在**你浏览器本地的 localStorage**，不依赖任何服务器与数据库，可直接托管到 GitHub Pages 免费运行。开启「微信同步」后数据存于云端，手机/电脑多设备实时同步。

## 功能一览
- 📋 **待办事项**：增删改、优先级、截止日、逾期提醒
- 📈 **投资跟踪**：自选股票/ETF 实时行情（东方财富接口）、成本与浮动盈亏、ETF 定投加仓建议
- 💰 **记账本**：收支流水、本月/累计结余
- 👧 **小孩教育**：识字闯关进度、学习/锻炼打卡、本周统计
- ✅ **习惯打卡**：自定义习惯、每日一键打卡、连续天数(🔥)统计、最近 7 天视图、打卡记录
- ⚡ **快捷入口**：常用工作/学习网站一键直达
- 💬 **微信同步**：微信快捷录入 + 云端多设备同步，见下文

## 本地预览
直接用浏览器打开 `index.html` 即可使用（无需安装任何依赖）。

## 部署到 GitHub Pages
**方式一（推荐，无需写代码）：**
1. 在 GitHub 新建仓库（如 `personal-workbench`），把本目录所有文件推送上去。
2. 仓库 `Settings → Pages → Build and deployment → Source` 选择 **Deploy from a branch**，分支选 `main`、目录选 `/ (root)`，保存。
3. 几分钟后访问 `https://<你的用户名>.github.io/personal-workbench/`。

**方式二（GitHub Actions 自动部署）：**
本仓库已内置 `.github/workflows/pages.yml`。推送 `main` 分支后自动部署，并在 `Settings → Pages` 选择 **GitHub Actions** 作为源。

## 个性化
点击右上角 **⚙ 设置**，可修改：
- **称呼 / 工作台名称**（如「汤工的专属工作台」）
- **微信同步（云端）**：填写 Supabase 地址 + 同步口令，开启多设备同步（可选）

## 打通微信（微信同步）
### 1) 微信快捷录入（纯前端，立即可用）
在「⚡ 快捷入口 → 💬 微信快捷录入」中，选择待办/记账/打卡/习惯，填写内容，点「生成分享链接 + 二维码」。
把链接或二维码发到微信（文件传输助手 / 自己），**用常用设备打开该链接**，即自动录入到本工作台。

> 配合「微信同步」（见下节）开启后：从微信打开链接录入的待办/记账/打卡会写入云端，自动出现在你所有已登录设备上。若未开启云端同步，数据只保存在「打开链接时所在的浏览器」，换设备请用「导出备份 / 导入备份」迁移。

### 2) 微信同步 = 云端多设备同步（Supabase）
默认数据存本地浏览器。若要在手机/电脑多设备实时同步，可接入免费的 [Supabase](https://supabase.com)：
1. 新建项目，在 **SQL Editor** 执行本仓库 `supabase/schema.sql` 建表。
2. 打开 `Settings → API`，复制 **Project URL** 与 **anon public key**。
3. 在工作台右上角 **⚙ 设置** 中填写：Supabase URL、Anon Key、自定义「同步口令」，点「测试连接」后保存。
4. 之后所有数据读写走云端，换设备只需填同样的 URL/Key/口令即可恢复同一份数据。

> 这就是「微信同步」的完整含义：在微信里录入 → 写入云端 → 所有设备可见，等价于一个轻量微信账号体系，且无需企业微信/公众号资质。

### 关于「微信扫码登录」
纯静态站点（GitHub Pages）无法独立完成微信 OAuth 扫码登录——它需要后端用公众号/企业微信的 Secret 换取用户信息，且回调地址须为已备案的 https 域名。因此本项目用上面的「同步口令 + 云端」方案替代扫码登录，达到同样的「多设备同一份数据」效果，且零资质门槛。若你以后确实需要原生扫码入口，可作为进阶项单独评估（需已认证公众号或服务号）。

## 数据安全与隐私
- 未开启同步时，所有数据仅存于你当前浏览器，**不上传任何服务器**。
- 开启同步后，数据存于你自己的 Supabase 项目（你完全掌控）；「同步口令」仅用于区分数据，请使用足够随机的口令。
- 定期使用「导出备份」下载 Json，换设备或清理浏览器前务必备份。
